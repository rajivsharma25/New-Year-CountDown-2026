# 🎆 New Year 2026 Countdown

A beautifully designed countdown timer built using **HTML**, **CSS**, and **JavaScript**. It counts down to **1 January 2026** and includes a smooth progress bar showing how much of the current year has passed.

---

## 🌍 Live Demo

**[https://rajivsharma25.github.io/New-Year-CountDown-2026/](https://rajivsharma25.github.io/New-Year-CountDown-2026/)**

---

## ✨ Features

* Real-time countdown (Days, Hours, Minutes, Seconds)
* Smooth animated yearly progress bar
* Modern gradient UI
* Responsive layout
* Uses Google Fonts (Poppins)
* Clean, simple, and readable code

---

## 🛠️ Technologies Used

* **HTML5**
* **CSS3** (Flexbox, Gradients, Responsiveness)
* **JavaScript** (DOM manipulation & setInterval)

## ⏱️ How It Works

### Countdown Logic

* Target date: **1 January 2026, 00:00:00**
* Calculates Days, Hours, Minutes, Seconds
* Updates every second using `setInterval()`

### Progress Bar

* Start date: **1 Jan 2025**
* End date: **31 Dec 2025**
* Calculates percentage of the year passed
* Progress bar fills smoothly with CSS transitions
